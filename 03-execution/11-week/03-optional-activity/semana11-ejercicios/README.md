# Semana 11 - Ejercicios SQL resueltos

**Proyecto:** Carrito de compras para la cafetería del SENA  
**Aprendiz:** Johan Steven Rodriguez Charry  
**Tema:** Consultas, procedimientos almacenados y triggers sobre el modelo de datos.

## Contenido

Esta carpeta contiene ejercicios propios basados en el sistema de cafetería:

1. Gestión de productos e inventario.
2. Registro de pedidos y cálculo de total.
3. Cambio de estado de pedidos.
4. Control de clientes y trazabilidad de compras.
5. Auditoría básica de cambios en productos.

Cada ejercicio incluye:

- Documento explicativo en Markdown.
- Script de configuración (`setup`).
- Script de demostración (`demo`).

## Nota

Los scripts están escritos para MySQL 8.x y pueden ejecutarse desde MySQL Workbench o consola.
