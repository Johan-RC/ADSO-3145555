# Ejercicio 03 - Cambio de estado de pedidos

## Contexto
La cafetería necesita actualizar el estado de los pedidos para saber si están pendientes, en preparación, entregados o cancelados.

## Dominios involucrados
- Pedidos
- Clientes

## Objetivo
Crear un procedimiento para cambiar el estado de un pedido.

## Solución propuesta
Se crea el procedimiento `sp_cambiar_estado_pedido`, que recibe el identificador del pedido y el nuevo estado.

## Resultado esperado
El personal de la cafetería puede actualizar el estado del pedido de forma controlada.
