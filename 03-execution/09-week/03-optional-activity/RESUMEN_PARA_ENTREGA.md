# Resumen Semana 9

Durante la semana 9 se elaboraron ADRs relacionados con el modelo de base de datos del proyecto de cafetería.

Un ADR es un registro de decisión de arquitectura. Sirve para documentar qué decisión se tomó, por qué se tomó, qué alternativas se evaluaron y qué consecuencias puede tener.

Las decisiones documentadas fueron:

1. Definición de la tabla productos.
2. Separación entre pedidos y detalle de pedido.
3. Manejo de estados del pedido.
4. Registro de fechas de creación y actualización.
5. Uso de Liquibase y ambientes.
